information while maintaining a professional and visually appealing interface.
Core Features:
Complete form with all required fields (name, contact, address, company, email, department, gender)
Responsive design that adapts to different screen sizes
Subtle animation effects on input focus and button hover
Modern, visually appealing layout with proper spacing and alignment
Clear visual feedback for user interactions
